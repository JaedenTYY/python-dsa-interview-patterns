# Eight-Week Study Plan

Use five study days, one review day, and one rest day each week. Spend 60–90 minutes per study day.

| Week | Focus | Outcome |
|---:|---|---|
| 1 | Linear scans, sets, maps, prefix sums | Comfortable with Python collections and one-pass state |
| 2 | Two pointers and sliding windows | Can distinguish pairs from contiguous-window problems |
| 3 | Stacks, queues, binary search | Can explain LIFO/FIFO and search invariants |
| 4 | Linked lists and intervals | Can safely rewire references and merge ranges |
| 5 | Tree DFS and BFS | Can choose recursion versus a queue |
| 6 | Graph traversal, topological sort, union-find | Can model connectivity and dependencies |
| 7 | Heaps and backtracking | Can maintain Top K and enumerate choices |
| 8 | Dynamic programming, cyclic placement, bits | Can define state/transitions and handle specialised constraints |

## Daily structure

1. **10 minutes:** recall yesterday's invariant and template from memory.
2. **15 minutes:** learn today's recognition clues and derive the template.
3. **30–45 minutes:** solve one problem without looking at the answer.
4. **10 minutes:** write mistakes and the corrected reasoning.
5. **5 minutes:** explain the solution aloud as if in an interview.

## Problem ladder

For each pattern, choose:

- one easy mechanics problem;
- one medium standard variation;
- one medium problem whose pattern is not named;
- one timed revisit after a week.

Do not count a copied solution as a solved problem.
